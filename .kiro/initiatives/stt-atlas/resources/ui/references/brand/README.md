# Activos de marca — ST&T

Carpeta destino de los activos corporativos que ST&T debe proveer para los mockups y la implementación.

## Pendiente de entrega

| Activo | Uso | Estado |
|---|---|---|
| Logotipo principal | Barra superior y pantalla de ingreso | Pendiente |
| Logotipo compacto o isotipo | Navegación colapsada y favicon | Pendiente |
| Paleta corporativa | Color de acento y neutros | Pendiente |
| Tipografía corporativa | Jerarquía de texto | Pendiente |

## Nota

Mientras estos activos no estén disponibles, los prompts describen la marca de forma neutra —neutros con un único color de acento— y las imágenes generadas se consideran preliminares en cuanto a identidad visual. La estructura y el contenido de las pantallas sí son válidos como referencia.
